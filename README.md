# domi homestudio

domi 综合手作工作室宣传网站的首版预览，包含拼豆、美甲和热缩片手绘项目介绍、老板与小恐龙 domi 的品牌故事、预约意向演示。

## 本版本

- 采用已确认的品牌插画、粉色爱心与蓝绿配色。
- 支持电脑与手机布局。
- 项目按钮可预选预约项目；表单校验后显示预约摘要，支持复制。
- 预约仅为演示，不发送、不保存数据，也不代表实际名额。
- 微信、地址、营业时间等待店铺补充；尚未接入真实预约服务。

## 查看页面

GitHub 仓库中的网页文件位于根目录。下载全部文件后打开 `index.html` 即可查看；复制功能建议在 localhost 或 HTTPS 下使用。

也可以在文件所在目录运行 `python -m http.server 4173`，然后访问 `http://localhost:4173`。

## 文件

- `index.html`：页面结构与中文内容。
- `style.css`：品牌样式和响应式布局。
- `app.js`：项目选择、预约校验、摘要与复制。
- `domi-logo.png`：当前品牌图标。
- `owner.png`：老板与 domi 的卡通形象。
- `favicon.svg`：浏览器图标。

本仓库用于保存当前版本，未开启公开网站发布。
