# domi homestudio

domi 综合手作工作室宣传网站的首版预览，包含拼豆、美甲和热缩片手绘项目介绍、老板与小恐龙 domi 的品牌故事、预约意向演示。

## 本版本

- 采用已确认的品牌插画、粉色爱心与蓝绿配色。
- 支持电脑与手机布局。
- 项目按钮可预选预约项目；表单校验后显示预约摘要，支持复制。
- 官网预约表单仍为演示，不会替客人提交。
- 本地后台可查看占用并写入真实档期到 `bookings.json`，前台周历刷新后显示已约。
- 微信、地址等待店铺补充。

## 查看页面

在项目目录运行：

```
python server.py --port 5172
```

然后打开 `http://localhost:5172/` 看官网，`http://localhost:5172/admin` 看预约后台。后台没有登录，请不要公开分享该地址。

只预览静态页时仍可用 `python -m http.server 4173`，但那样后台无法写入预约。

## 文件

- `index.html`：页面结构与中文内容。
- `style.css`：品牌样式和响应式布局。
- `app.js`：项目选择、预约校验、摘要、周历。
- `admin.html` / `admin.js`：本地预约后台。
- `server.py`：本地静态服务与预约读写接口。
- `bookings.json`：营业时段与预约占用。
- `domi-logo.png`：当前品牌图标。
- `owner.png`：老板与 domi 的卡通形象。
- `favicon.svg`：浏览器图标。

本仓库用于保存当前版本，未开启公开网站发布。
